# 视觉规范（从目标站点实测提取）

> 用途：即使打不开 huajianlab.cn，也能靠这份把视觉做到接近。
> 数值来自 `getComputedStyle` 与截图像素采样，不是目测。

## 0. 三套主题，别混用

| 场景 | 主色 | 背景 | 文字 |
|---|---|---|---|
| 营销首页 Hero | 深 | `#10191f` | `#d2dce3` |
| 实验库 / 详情 / 我的 | 浅 | `#f5f7fa` | `#182630` |
| 实验室舞台 | 深 | `#10191f → #183541` 渐变 | `#d2dce3` |

**注意**：首页整体 body 是浅色 `#f5f7fa`，只有 Hero 区是深色块。不是全站暗色。

```css
:root{
  --bg-page:        #f5f7fa;
  --bg-card:        #ffffff;
  --border:         #dce3e9;
  --border-card:    #e0e7ed;
  --divider:        #edf0f3;

  --text-primary:   #182630;
  --text-secondary: #51616e;
  --text-muted:     #61717d;

  --brand-600:      #0877ad;   /* 主色，按钮/链接 */
  --brand-hover:    #075c87;
  --brand-100:      #e6f3fc;   /* 浅底高亮 */

  --danger:         #b33232;
  --success:        #26714e;

  --radius-sm:      5px;
  --radius-card:    10px;
}
```

## 2. 颜色 Token（深色区 / 实验室）

```css
:root{
  --dark-bg:        #10191f;   /* 顶栏、舞台顶部 */
  --dark-surface:   #102730;   /* 卡片/HUD 底 */
  --dark-border:    #2d373e;
  --dark-text:      #d2dce3;

  --lab-bg-top:     #10191f;
  --lab-bg-mid:     #183541;   /* 舞台渐变中段，偏青 */
  --lab-hud-line:   #4a9d92;   /* HUD 描边（青色，可略调亮） */
  --lab-hud-text:   #d8f0ec;
}
```

实验室背景是**从上到下 `#10191f → #183541` 的径向/线性渐变**，不是纯色。这一条决定了"高级感"，别用平涂。

## 3. 字体

```
-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
"Microsoft YaHei", sans-serif
```

**系统字体栈，没有自定义字体。** 不需要买字库、不需要字体文件。

| 元素 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|
| Hero H1 | 67.68px（clamp） | 750 | 82.57px | -3.05px |
| 区块 H2 | 44.64px | 650 | — | 负字距 |
| 正文 | 15–16px | 400 | 1.6 | 0 |
| 元信息/标签 | 12–13px | 500 | — | 0.04em |
| HUD 数字 | 12–14px | 500 | — | 用等宽数字 |

**大标题必须带负字距**（-0.04em 左右），这是"精致感"的来源之一。

## 4. 组件规格

### 导航栏
- 高度 **68px**
- 背景 `#10191f`，底部 1px `#2d373e`
- 菜单项 15px / 500，当前项底部 2px 主色下划线

### 实验卡片（列表页）
```
background: #fff
border: 1px solid #e0e7ed
border-radius: 10px
padding: 7px 7px 0        ← 注意上/左/右都是 7px，底部 0
box-shadow: 0 2px 5px rgba(23,54,72,.016)
```
缩略图区高约 **165px**，里面是几个器材 PNG 并排（`max-width:20%` 各自）。

### 筛选 chip
- 高 32–36px，圆角 999px（胶囊）
- 未选中：透明底 + 1px `#dce3e9`
- 选中：`#e6f3fc` 底 + `#0877ad` 字

### HUD 数据框（实验室）
- 底：`rgba(16,39,48,.72)` 半透明
- 边：1px `#4a9d92`，圆角 4px
- 四角有小刻度装饰（短横线）
- 文字：标签 11px 青色半透明，数值 13–14px 亮色 + 等宽
- 面板之间用 1px 细线分隔

### 器材格（右侧面板）
- 80×96 左右，圆角 6px
- 底 `#151718`，hover 提亮到 `#1c1f20`
- 器材图**灰色半透明**（不是彩色），统一色调

## 6. 实验室舞台的三层结构

```
底层：渐变背景（#10191f → #183541）+ 极淡网格纹理
中层：器材（锥形瓶居中，滴管分列两侧）
顶层：HUD（绝对定位，不挡操作区）+ 底部提示条
```

**关键**：HUD 不是浮在器材上，是**贴着器材边缘**排布，像仪表的读数框。这个布局比"居中弹窗"高级得多。

---

## 7. 动作与节奏（从操作中观察到）

| 动作 | 时长 | 曲线 |
|---|---|---|
| 液面升降 | 400–600ms | ease-out |
| 颜色变化 | 600–800ms | ease |
| 滴管下移+回弹 | 300ms + 200ms | ease-in-out |
| 工具栏 hover | 120–150ms | linear |
| 卡片 hover | 200ms | ease |

**不要用弹性/回弹曲线**（spring），这个站整体是"克制、平稳"，不是活泼。

---

## 8. 复刻时的取舍建议

| 值得一模一样 | 可以不一样 |
|---|---|
| 三套主题的分工 | 具体色值（偏几度看不出来） |
| 大标题的负字距与字号比例 | 字体（系统字体即可） |
| 卡片 10px 圆角 + 7px 内边距 | 卡片阴影强度 |
| HUD 贴边而非居中 | HUD 的刻度装饰细节 |
| 实验室渐变背景 | 渐变的色相（青一点/蓝一点都行） |

**最容易被忽略、但最影响观感的三件事**：
1. 大标题的负字距
2. 实验室背景的渐变（不是平涂）
3. HUD 贴着器材排布，不是居中浮层
