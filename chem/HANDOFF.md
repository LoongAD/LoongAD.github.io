## 0. 一句话目标

用户要做一个**初中化学虚拟实验平台**，对标 huajianlab.cn，**除了登录注册和商业化之外尽可能复刻全套**：

```
首页（营销） → 实验库（章节树 + 搜索） → 实验详情 → 交互实验室
```

目标用户：初中化学教师（课堂演示 / 备课），以及学生的课后复习。

## 2. 最重要的实测结论（别错过）

### 2.1 宣传图 ≠ 实际效果

首页那张 `free-lab.webp` 是**精修渲染图**（写实玻璃、摄影棚打光）。实际进实验室看到的器材：

- 「仪器识别」实验：**扁平 SVG 线条**，没有质感
- 「中和反应」实验：简单渐变 + 一层高光 + 投影的锥形瓶

**所以不要拿宣传图当验收标准，那是对不上的。** 参考截图在 `ref/` 目录。

### 2.2 它没有物理引擎

「中和反应」实验底部有一行小字，是整件事的钥匙：

> 克数、浓度与每滴 0.20 g 为教学模型参数，并非教材指定用量；**液面按 1 g/mL 示意，不表示真实密度**。

即：
- 液面高度 = 质量 × 1g/mL（线性换算，不是流体模拟）
- 反应结果 = 化学计量计算后改数字和颜色
- 没有粒子、没有流体、没有碰撞

**复刻不需要 Matter.js / Three.js。**

### 2.3 三种实验形态，没有一个是模拟器

| 形态 | 实例 | 本质 |
|---|---|---|
| 分类拖拽题 | U1-04 仪器识别：5 个分类框 + 11 个器材 | 拖拽 + 判定对错 |
| 参数化操作 | D10-11 中和反应：左侧参数 → 确认投料 → 滴加 → HUD 变化 | 表单 + 状态机 + 化学计算 |
| 自由沙盒 | `/free-lab` | 未深入验证（见 §6） |

### 2.4 舞台结构（中和反应，可当模板）

```
┌ 顶栏：返回 / 实验名 / 教学辅助 / 帮助 / 全屏 / 账号
├ 左侧（可切「器材」「条件」两个 tab）
│   ├ NaOH 溶液质量（模拟）：10g | 20g
│   ├ NaOH 质量分数（模拟）：1% | 2%
│   ├ 稀盐酸滴管装液质量（模拟）：1g | 5g | 10g
│   ├ HCl 质量分数（模拟）：5% | 10%
│   ├ 确认本轮克数：[未确认] → 确认投料
│   ├ 滴加酚酞至锥形瓶：每次 0.02 g
│   ├ 逐滴加入稀盐酸：每次 0.20 g
│   ├ 连续滴加到限量上限
│   └ 记录中和结论：[未记录] → 记录结论
├ 中间：WebGL canvas 舞台
│   ├ 中央锥形瓶（液面随质量变化）
│   ├ 左右两根可拖拽滴管（酚酞 0.12g / 稀盐酸 10.00g）
│   └ 4 个 HUD 数据框：
│       「HCl + NaOH → NaCl + H₂O」
│       「H⁺ + OH⁻ → H₂O」
│       「剩余 OH⁻ 0.100 g」
│       「新增 H₂O 0.000 g」「H⁺ 过量 0.000 g」
└ 底部：重置 / 撤销 / 暂停 / 0.5× 1× 2× / 现象
```

### 2.5 交互有前置校验

没点「确认投料」就点「滴加」，底部提示 **「当前操作不可执行」**。这是教学设计（逼学生先定量再操作），不是技术限制。复刻时值得保留——它让实验有"步骤感"。

### 2.6 关键洞察：真正值钱的是 HUD

用户（老师）愿意付费的不是"好看的动画"，是 **HUD 上那几个数字**——剩余 OH⁻、生成的水、H⁺ 是否过量。因为考试要考这些。

**做产品时，数据反馈的优先级高于视觉效果。**

### 3.1 原型的技术形态

- 纯 HTML + CSS + 原生 JS，无构建、无框架、无依赖
- 器材用 **SVG 绘制**（`GEO` 里存 clip path 与 outline path）
- 状态：`state.vessels[]` + `REAGENTS[]` + `RULES[]`
- 反应：`RULES` 里写 `pair:['cuso4','naoh']`，命中后变色/沉淀/冒泡
- 渲染：**增量更新**（`render()` 只更新属性，不重建 DOM），否则液面过渡和气泡会消失
- 已内置 5 个反应：CuSO₄+NaOH 沉淀、Na₂CO₃+HCl 气泡、酚酞+NaOH 变红、两个对照

**它现在缺的正是 HUD 层**（见 §7 第一步）。

## 4. 已做的技术决策（不要推翻重来）

| 决策 | 理由 |
|---|---|
| **不上 React / Next.js** | 用户是单人维护，改一条反应规则不该需要重新构建；Astro 若需要也只在内容层 |
| **不上物理引擎** | 竞品自己都没用；液面是线性换算 |
| **器材用 SVG 不用图片** | 液体要贴着圆底走、尺寸要能改；也避免版权风险 |
| **反应写成数据表** | 加实验 = 加一行配置，不是写代码 |
| **纯静态优先** | 没有账号/付费时，静态站零运维、零攻击面、可离线 |

### 选型结论（详见 STACK.md）

- 站点骨架：**Astro**（63.3k★, MIT），产物纯静态
- 搜索：**Pagefind**（5.5k★, MIT）或 Fuse（20.5k★, Apache）
- 动画：**Motion**（34.4k★, MIT）或 Lenis（16.7k★, MIT）
- 交互升级（器材 >10 件时）：Konva（14.9k★）+ Matter.js（18.5k★）
- 3D（最后考虑）：Three.js（116.6k★）

**GitHub 上没有可直接用的虚拟化学实验室**——全是 0–2★ 的学生作品且无 license。PhET 质量高但限非商业、单个仓库已停维护、代码拿不走。

## 7. 下一步（按优先级）

### 第一步：给原型加 HUD 层（建议立刻做）

用户已经看过竞品的中和反应，最可能期待的就是这个。改动量约 300–400 行：

1. `state` 里加 `mass`、`concentration`、`moles` 等计量字段
2. 台面上叠一层 HUD：绝对定位在容器周围，青色描边 + 刻度装饰
3. 每次操作后重算：`c = m × w%`、`n = c / M`、剩余 OH⁻、生成 H₂O
4. 数据框用 SVG 或 DOM 都行，注意别挡住拖拽

参数建议（照抄竞品的教学模型即可）：
- NaOH：10g / 20g，浓度 1% / 2%
- 稀盐酸滴管：1g / 5g / 10g，HCl 5% / 10%
- 每滴盐酸 0.20 g，每滴酚酞 0.02 g
- 液面 = 质量 × 1 mL/g

### 第二步：实验库（1–2 周）

Astro + 32 个实验的 JSON 数据 + 章节树 + 类型筛选 + Pagefind 搜索。卡片缩略图可以先用 SVG 器材组合，不必做 32 张渲染图。

### 第三步：单个实验的场景化

现在是一张通用台面。真实产品里每个实验要不同的器材组合（铁丝燃烧要集气瓶、过滤要漏斗铁架台）。建议先做 3 个不同类型的实验验证，再批量。

最后做。竞品自己都标"开发中"，说明不是刚需。

## 8. 怎么复现我的观察（硬知识，能省几小时）

如果要再看竞品，按这个来：

```python
# 1) 登录是弹窗，不是 /login（该路径 404）
#    首页点导航栏「登录」→ 出现 modal，字段是 email + password
# 2) 输入框带 readonly（防自动填充），fill() 会超时！
#    必须：click 输入框 → 等 300ms → keyboard.type()
pg.locator("input[type=email]").click()
pg.keyboard.type("邮箱", delay=30)
pg.locator("input[type=password]").click()
pg.keyboard.type("密码", delay=30)

# 3) 舞台是 WebGL，headless 模式一定失败：
#    "Flaskora stage initialization failed"
#    必须用有头 + Xvfb + SwiftShader：
#    xvfb-run -a python3 script.py
b = p.chromium.launch(headless=False, args=[
    "--no-sandbox", "--use-gl=swiftshader",
    "--enable-unsafe-swiftshader", "--disable-dev-shm-usage"])
# 4) 舞台加载慢，SwiftShader 软件渲染，等 15–18 秒
# 5) 实验 URL 是 /lab/<编号>（U1-04、D10-11），不是 slug
# 6) 交互按钮在左侧滚动区，用 get_by_role("button", name="...") 更稳
```

**注意**：它登录后把 token/cookie 存在 storage_state 里，别提交、别写进文档。
