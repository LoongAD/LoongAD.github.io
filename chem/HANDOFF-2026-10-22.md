## 1. chem-lab 是什么

鲁教版九年级化学（2024 版）教学站，纯静态：

- **30 个可交互虚拟实验**（上册 15 + 下册 15，含 9 个跨学科实践）
- **11 单元 / 44 节 / 144 条知识点**（含 9 个跨学科实践活动），45 个化学方程式
- **38 份教学资料**（指向 `chem-resources` 仓库，`resources.html` 按单元分组）
- **9 套在线自测**（上册 4 + 下册 5）

设计定位：**教材 / 实验报告的印刷感**，纸白底 + 墨黑字 + 绯红强调 + 细线分层。不是深色科技风，因为要投屏、要打印、要在手机上看。

### 实验的数据结构

```js
{
  id: 'u1-02', code: 'U1-02', title: '量筒的量取与读数',
  book: '上册', unit: '第一单元 步入化学殿堂', kind: '基本操作',
  opening: '一句话说明（列表页会显示）',
  stageNote: '舞台下方的小字',
  init: () => ({ vol: 50, eye: 'level' }),
  svg: `<svg viewBox="0 0 460 400">…</svg>`,        // 静态骨架，只建一次
  draw(s, el, api) { /* 用 el.querySelector('#id') 改属性，动画靠 CSS transition */ },
  controls(s) { return [ … ]; },                    // 参数控件
  hud(s) { return [{ label, value, hi }]; },        // 右侧实时数据
  after(s, api) { … },                              // 每次更新后跑，用于判定/提示
  actions: { key(s, api) { … } },                   // 操作按钮
  actLabels: { key: '按钮文字' }
}
```

控件四种类型：`range` / `seg` / `steps` / `opts`（外加 `note` 纯文本）。
提示与结论：`api.say(html, 'ok'|'warn'|'bad')`、`api.conclude(标题, [条目])`、`api.clearConcl()`。

### 加一个实验

在 `data/ex-upper.js` 或 `ex-lower.js` 里 push 一个对象即可。实验库列表、上一个/下一个导航都会自动出现，不用改任何 HTML。

`stageNote`、`opening` 里的 HTML 标签会被列表页剥离，写 `<b>` 没问题。

## 3. 本地怎么跑

**不要双击 HTML**（浏览器拦 file:// 的脚本）。起静态服务：

```bash
cd chem-lab
python3 -m http.server 8000
# http://127.0.0.1:8000/
```

我这次用的端口是 8765，可用可不用。

### 部署

```
仓库：github.com/LoongAD/chem-lab（公开，main 分支）
Pages：https://loongad.github.io/chem-lab/
```

这台沙箱 **`github.com` 直连超时**，`git push` 走不通；只能走 `api.github.com` 的 Contents API（base64 PUT）。改完文件上传后 **Pages 要等 40–90 秒**，期间可能 404，属正常。

用程序核对，不靠肉眼。

**方法**：把 5 个数据文件里的方程式全部提取出来，写解析器（处理下标、括号、结晶水、条件标注），按元素统计左右原子数。

| 化学式清单 | 40+ 种（含 C₆H₁₂O₆、C₁₂H₂₂O₁₁），无错写 |
| 数值断言 | 空气成分、元素含量、质量分数、含碳量、溶解度，全部复核 |

**修掉的问题**：

1. **中和反应计量错了**：把 0.5 g 当成溶液质量，实际是纯 NaOH 质量，差 50 倍。原来第一滴就过量，pH 一步从 13.7 跳到 1.4；现在第 10 滴才到终点，前 9 滴有渐变。
2. **电解氯化镁缺条件**：补「熔融」，水溶液电解得不到镁。
3. **pH 试纸表述不准**：原文「不能测气体」→ 改为「测的是溶液，测 CO₂ 要先通入水中」。
4. **题库套题名与教材单元号不符**：3 套改名为「步入化学殿堂」「物质的构成与水」「溶液 · 专题」。
5. **空气成分数字不一致**：题库写 0.934%/0.038%，知识点写 0.94%/0.03%，已统一为后者。
6. **实验类型标错 2 个**：电解水应为「课标必做」（学生实验 2）、测定氧气含量应为「教材演示」（节内探究）。

**两个学生实验的教材依据**（不是凭记忆写的）：

- S06 对照山东教育出版社官方实验视频 + 鲁教版 2024 学案：锥形瓶装石灰石、分液漏斗加稀盐酸、收集 1 集气瓶 + 3 塑料瓶、天平法比较密度、塑料瓶变瘪、石蕊变红、石灰水变浑浊、高低蜡烛自下而上熄灭。
- S10 对照鲁教版学生实验 10 导学案与教学设计：洗净去内膜烘干研碎 → 称 m₁ → 加足量稀盐酸 → 冷却后称 m₂ → 质量差算 CO₂ → 按方程式求 CaCO₃ → 算质量分数。

**仍不能保证的**：现象措辞的教材贴合度（各版本表述有差异）、实验里的教学模型参数（页面已注明「不等同真实用量」，如蛋壳含钙量按 90% 设定）。

## 6. 设计系统速查

```css
--paper:   #f8f6f1;   /* 纸白 */
--ink:     #1a1815;   /* 墨黑 */
```

### 13.4 五个功能
1. **三边互通**：知识点每节挂"实验 →"（`SEC_LAB` 表），实验页底部挂"本单元知识点 / 自测"。
2. **错题本**：localStorage `chemWrong`，提交时写入、答对时移除，自测列表出现"错题本"条目。
3. **侧边目录**：`knowledge.html` 左侧 sticky 目录，IntersectionObserver 高亮，≤960px 隐藏。
4. **实验报告导出**：实验页"导出实验报告"→ 新窗口 A4 排版（目的/参数/数据/结论/档案），可直接打印或存 PDF。
5. **全站搜索** `search.html`：实验 + 知识点 + 自测 + 资料，支持中文名↔化学式互搜（`ALIAS` 表）。

### 13.5 已知取舍
- 搜索的别名表只覆盖常见物质，冷僻物质需补 `ALIAS`。
- 报告导出用 `window.open` + `document.write`，被弹窗拦截器拦时需手动允许一次。
- 知识点页现在额外加载两份实验数据（约 200 KB 未压缩），换来"每节挂实验"的入口。
